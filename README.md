# TrueROAS Decision Intelligence

TrueROAS is a high-integrity, self-hosted decision engine designed for DTC (Direct-to-Consumer) brands to reconcile Meta Ads attribution with ground-truth Shopify revenue. It protects ad spend by identifying "Truth Gaps" and preventing capital leakage through mathematically defensible Bayesian logic.

## Key Value Propositions

- **The Truth Gap:** Reconciles overstated Meta ROAS with actual bank revenue using a `BayesianInferenceEngine`.
- **Strictly Local (Air-Gapped):** All PII (Personally Identifiable Information) and financial data remain on your server. External egress to APIs is blocked by default.
- **Capital Preservation:** Includes a real-time `AdSpendBreaker` (Circuit Breaker) that automatically pauses or flags inefficient campaigns.
- **WORM Compliance:** All strategic decisions are logged in a "Write Once, Read Many" (WORM) audit trail with HMAC-SHA256 digital signatures for IRS-ready auditing.

## Core Architecture

- **FastAPI:** High-performance asynchronous API layer.
- **Hybrid Multi-Tenancy:** Central metadata in PostgreSQL with isolated analytical warehouses in DuckDB for each brand.
- **Decision Orchestrator:** Unifies Bot Detection, Data Quality, and Economic Risk Analysis into actionable strategic narratives.
- **Celery + Redis:** Robust background processing for data synchronization and automated reconciliation.

## Setup & Installation

1. **Environment Configuration:**
   Copy `.env.example` to `.env` and configure your `APP_SECRET_SALT` (min 32 chars).

2. **Docker Deployment:**
   ```bash
   docker-compose up -d --build
   ```

3. **Initialize Database:**
   ```bash
   python -m src.trueroas.core.migrations
   ```

## Security & Compliance

- **Data Residency:** Built for strictly on-premise or private cloud execution.
- **Encryption:** PII is hashed using BLAKE2b with per-tenant versioned salts.
- **Audit Integrity:** WORM-compliant logs prevent the manipulation of historical performance records.

## API Endpoints (Quick Reference)

- `POST /api/v1/sync`: Trigger Meta/Shopify data reconciliation.
- `GET /api/v1/analysis/metrics`: Fetch risk-adjusted ROAS and accuracy scores.
- `GET /api/v1/decisions/dashboard/capital-saved`: View real-time ROI generated by the system.
- `POST /api/v1/decisions/`: Ingest and sign a strategic ad spend decision.
